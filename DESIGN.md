# DESIGN.md — Operon Protocol Visual Contract

> Evidence-based design contract conforming to the Refero Design Protocol, Monad Metropolis Brand DNA, and Awwwards / MotionSites benchmarks.

---

## 1. Aesthetic Archetype & Mood
- **Archetype**: High-Performance Mission Control & Institutional DeFAI Telemetry HUD.
- **Dominant Emotion**: Authoritative, Cryptographic Precision, Unstoppable Velocity.
- **Strict Anti-Patterns Banned**:
  - No generic purple/blue mesh blur blobs.
  - No 2D floating constellation dots.
  - No flat digital black voids without lighting or texture.
  - No cookie-cutter 3-card repeating grids.
  - No high-frequency React re-renders across component trees.

## 3. Typography Hierarchy
- **Primary Sans / Headings**: Inter / System Sans with tight tracking (`tracking-tight`, font-weight `600` / `700`).
- **Telemetry & Hashes**: Monospace (`ui-monospace, SFMono-Regular, "JetBrains Mono", Menlo, monospace`).
- **Scale**:
  - `Hero Title`: 28px–32px / line-height 1.15 / tracking -0.02em
  - `Panel Header`: 14px / line-height 1.3 / tracking +0.02em / uppercase
  - `Body`: 13px–14px / line-height 1.5
  - `Data Metric`: 20px–24px / font-mono / font-bold
  - `Telemetry Ticker`: 11px–12px / font-mono / tabular-nums

## 4. Layout Architecture & Composition
- **Screen Archetype**: Split-Screen Command Center.
  - **Left Pane (Governance & Delegation)**:
    - Master WebAuthn Passkey Status (P256 badge, Touch ID/Face ID prompt).
    - "One Passkey, Many Keys" Delegated Sub-Key Matrix with visual derivation tree.
    - Spend Cap sliders, Whitelist toggles, and Expiry controls.
    - Tactical Emergency Circuit Breaker (prominent tactile switch).
  - **Right Pane (Parallel Telemetry & Execution)**:
    - Live 60 FPS Monad Parallel Execution Canvas (particle flow & sub-second block pulse).
    - Autonomous Operator Intent Input + Multi-Order Stress-Test Trigger.
    - Verified Onchain Transaction Stream with direct clickable Monad Explorer links.

---

## 5. Living Motion & Procedural Audio Law
- **60 FPS Hardware-Accelerated Canvas**: Direct requestAnimationFrame render loop on HTML5 Canvas using device pixel ratio scaling, zero React state re-render overhead.
- **Procedural Web Audio Engine**:
  - `playBiometricChirp()`: 880Hz -> 1760Hz frequency glide on passkey authentication.
  - `playMechanicalClick()`: 120Hz bandpass tactile click on toggle/slider adjustments.
  - `playTxMinedChime()`: Pentatonic chord resolving on sub-second transaction confirmation.
  - `playCircuitBreakerKlaxon()`: Low-frequency square wave warning on emergency freeze.
